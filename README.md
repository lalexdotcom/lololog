# lololog

Universal logger: log everywhere with style and low overhead.

## Status

Early development. The package builds and publishes, but the logger API is
not published yet.

## Install

```sh
npm install lololog
```

```sh
pnpm add lololog
```

## Requirements

Node.js >= 22.3.0, or any modern browser (ESM only).
